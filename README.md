# Slackr

A Slack-inspired full-stack web application that enables users to communicate through channels, exchange messages, and manage user accounts. The project demonstrates full-stack web development using JavaScript, RESTful APIs, and a client-server architecture.

> **Note:** This project was independently developed as part of my web development learning and portfolio. It showcases my ability to design and implement a complete web application from frontend to backend.

---

## Features

* User registration and login
* Authentication and session management
* Create and manage channels
* Join and leave channels
* Send and display text messages
* Image upload support
* User profile management
* Responsive single-page application (SPA)
* RESTful API communication between frontend and backend

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/UNSWRuilinZhao/slackr.git
```

### 2. Install dependencies

Backend

```bash
cd backend
npm install
```

Frontend

```bash
cd frontend
npm install
```

### 3. Start the backend server

```bash
cd backend
npm start
```

### 4. Start the frontend

Open the frontend according to the project configuration (or run the provided npm script if available).
